# delete-item Specification

## Purpose

Навык забывает вещь по просьбе пользователя: удаляет запись, найденную по
canonical_key нормализованного названия.

## Requirements

### Requirement: Удаление существующей вещи

При интенте `delete` с названием, чей canonical_key найден в хранилище, навык
SHALL удалить запись и подтвердить удаление.

#### Scenario: Вещь удаляется

```gherkin
Допустим в хранилище есть «паспорт»
Когда пользователь говорит «забудь про паспорт»
Тогда ответ содержит «Забыла»
И записи с canonical_key «паспорт#» больше нет в хранилище
```

*Трассировка: `tests/test_handler.py::TestDelete::test_deletes_item`*

#### Scenario: Синоним удаляет сохранённую вещь

```gherkin
Допустим в хранилище есть «смартфон» с canonical_key «телефон#»
Когда пользователь говорит «забудь про айфон»
Тогда canonical_key «айфон» совпадает с «телефон#»
Тогда ответ содержит «Забыла»
И записи с canonical_key «телефон#» больше нет в хранилище
```

*Трассировка: `tests/test_handler.py::TestNormalizeDelete::test_delete_by_synonym`*

### Requirement: Удаление неизвестной вещи

Если canonical_key не найден, навык SHALL сообщить, что воспоминаний об этой
вещи нет, и SHALL NOT изменять хранилище.

#### Scenario: Вещи нет в хранилище

```gherkin
Допустим хранилище пользователя не содержит вещь
Когда пользователь говорит «забудь про телефон»
Тогда ответ сообщает об отсутствии воспоминаний
И хранилище остаётся без изменений
```

*Трассировка: `tests/test_handler.py::TestDelete::test_delete_not_found`*
