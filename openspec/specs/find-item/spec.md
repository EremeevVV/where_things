# find-item Specification

## Purpose

Навык отвечает, где лежит вещь: ищет запись по canonical_key из нормализованного
названия и отвечает местом. Если вещь неизвестна — честно сообщает об этом.

## Requirements

### Requirement: Ответ местом для известной вещи

При интенте `find` навык SHALL найти запись по canonical_key и ответить фразой
«<вещь> <глагол> <место>», взяв глагол и место из хранилища.

#### Scenario: Точное совпадение

```gherkin
Допустим в хранилище есть «паспорт» с местом «в ящике» и глаголом «лежит»
Когда пользователь спрашивает «где лежит паспорт?»
Тогда ответ содержит место («ящик»)
```

*Трассировка: `tests/test_handler.py::TestFind::test_finds_exact_match`*

### Requirement: Сообщение о неизвестной вещи

Если записи с таким canonical_key нет, навык SHALL ответить, что не знает,
где лежит вещь, и SHALL NOT выдумывать место.

#### Scenario: Вещи нет в хранилище

```gherkin
Допустим хранилище пользователя не содержит вещь
Когда пользователь спрашивает «где лежит паспорт?»
Тогда ответ содержит «не знаю»
```

*Трассировка: `tests/test_handler.py::TestFind::test_unknown_item`*

### Requirement: Поиск по синониму через нормализацию

Навык SHALL находить запись, если название из запроса после нормализации даёт
тот же canonical_key, что и сохранённая вещь. В ответе используется название
из запроса пользователя, а не display_name из хранилища.

#### Scenario: Синоним находит сохранённую вещь

```gherkin
Допустим в хранилище есть «смартфон» с canonical_key «телефон#»
Когда пользователь спрашивает «где мобильник?»
Тогда canonical_key «мобильник» совпадает с «телефон#»
И ответ содержит место из хранилища
И ответ содержит слово «мобильник», а не «смартфон»
```

*Трассировка: `tests/test_handler.py::TestNormalizeFind::test_find_by_synonym`, `test_find_returns_intent_display_name`*
