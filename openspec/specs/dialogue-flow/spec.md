# dialogue-flow Specification

## Purpose

Оболочка диалога: приветствие новой сессии, реакция на нераспознанные команды,
корректный выход из машины состояний при смене темы и защита от неавторизованных
пользователей.

## Requirements

### Requirement: Приветствие новой сессии

При признаке новой сессии (`session.new`) навык SHALL поприветствовать
пользователя и подсказать примеры ключевых фраз («запомни…», «где лежит…»),
не завершая сессию.

#### Scenario: Подсказка при старте

```gherkin
Допустим начинается новая сессия
Когда пользователь открывает навык
Тогда ответ содержит подсказку с фразами «запомни» или «где лежит»
И атрибут end_session равен false
```

*Трассировка: `tests/test_handler.py::TestLaunch`*

### Requirement: Реакция на нераспознанную команду

Команды без известных интентов SHALL попадать в fallback: навык повторяет
услышанное и напоминает доступные фразы, не завершая сессию.

#### Scenario: Fallback-ответ

```gherkin
Допустим команда не совпала ни с одним интентом
Когда пользователь говорит нераспознанную фразу
Тогда ответ повторяет фразу и подсказывает «запомни» или «где лежит»
И атрибут end_session равен false
```

*Трассировка: `tests/test_handler.py::TestUnknown`, `TestFallback`*

### Requirement: Смена темы сбрасывает подтверждение

Из состояния `awaiting_confirmation` интенты `find`, `delete` и `list` SHALL
обрабатываться как обычные команды, а FSM-состояние ожидания подтверждения
SHALL очищаться без побочных записей.

#### Scenario: Вопрос посреди подтверждения

```gherkin
Допустим навык ждёт подтверждения обновления вещи
Когда пользователь вместо «да/нет» спрашивает «где лежит паспорт?»
Тогда выполняется обычный поиск
И FSM-состояние сброшено, отложенное обновление отменено
```

*Трассировка: `src/handlers.py::handle_interrupt`*

### Requirement: Неавторизованный пользователь получает приглашение авторизоваться

Запросы без данных пользователя (`session.user`) SHALL блокироваться
middleware с текстом о необходимости авторизации через Яндекс ID;
хранилище при этом не читается и не пишется.

#### Scenario: Запрос без user_id

```gherkin
Допустим запрос пришёл без session.user
Когда навык получает любую команду
Тогда ответ предлагает авторизоваться через Яндекс ID
И обращений к репозиторию нет
```

*Трассировка: `src/handlers.py::AuthMiddleware`, `tests/test_handler.py::TestUnauthorized`*
