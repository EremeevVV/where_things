# list-items Specification

## Purpose

Навык перечисляет, какие вещи он помнит, не раскрывая их местоположения.

## Requirements

### Requirement: Перечисление имён без мест

При интенте `list` навык SHALL перечислить display_name всех вещей пользователя
через запятую и SHALL NOT включать места или глаголы.

#### Scenario: Есть сохранённые вещи

```gherkin
Допустим в хранилище есть «паспорт» и «ключи»
Когда пользователь говорит «что ты помнишь?»
Тогда ответ содержит «паспорт» и «ключи»
И ответ не содержит мест («ящик», «шкаф»)
```

*Трассировка: `tests/test_handler.py::TestList::test_lists_names_only`*

### Requirement: Пустой список

Если у пользователя нет ни одной вещи, навык SHALL сообщить, что ничего не помнит.

#### Scenario: Хранилище пусто

```gherkin
Допустим хранилище пользователя пусто
Когда пользователь говорит «что ты помнишь?»
Тогда ответ содержит «ничего не помню»
```

*Трассировка: `tests/test_handler.py::TestList::test_empty_list`*
