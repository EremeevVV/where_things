# Где лежит вещь — навык Алисы

Голосовой навык для Яндекс Алисы (в первую очередь для Яндекс Станции), который помогает не терять вещи. Вы голосом говорите, куда положили вещь, навык запоминает это в памяти, привязанной к вашему аккаунту. Позже спрашиваете, где она лежит, — навык отвечает.

## Зачем это нужно

Каждый хоть раз искал паспорт, ключи от гаража, запасную зарядку или документы, которые «точно куда-то убрал». Идея навыка простая: в момент, когда вы кладёте вещь, проще сказать вслух «запомни, что …», чем потом полчаса вспоминать. Алиса становится внешней памятью для бытовых мелочей.

## Что умеет

- **Запомнить.** «Запомни, что паспорт лежит в верхнем ящике стола.»
- **Найти.** «Где лежит паспорт?» → «Паспорт — в верхнем ящике стола.»
- **Перечислить.** «Что ты помнишь?» → список сохранённых вещей.
- **Забыть.** «Забудь про паспорт.»

Если навык не знает, где вещь, он честно об этом скажет и предложит запомнить.

## Как это работает

Навык — это веб-сервис (вебхук): он принимает запросы от Яндекс Диалогов и отвечает текстом, который Алиса проговаривает. Технически:

- **Backend:** Yandex Cloud Functions (бесплатны для навыков Алисы).
- **Язык:** Python.
- **Хранилище:** Yandex Database (YDB) serverless — данные привязаны к `user_id` пользователя и сохраняются между сессиями.

Память между сессиями работает для пользователей, авторизованных через Яндекс ID. На Яндекс Станции вы всегда авторизованы, поэтому это основной и полностью рабочий сценарий.

## Статус

Проект в разработке, ведётся итерациями. Текущий шаг — минимальный рабочий каркас навыка (приветствие и эхо-ответ). Дальнейший план: разбор фразы на «вещь» и «место», многошаговый диалог с переспросом, подключение YDB, обработка крайних случаев и подготовка к публикации.

Подробности по архитектуре, ограничениям платформы и журнал итераций — в `PROJECT_INSTRUCTIONS.md`.

## Ограничения платформы (кратко)

- Ответ навыка должен укладываться в 4,5 секунды.
- Долговременная память работает только для авторизованных пользователей.
- Активационное имя навыка не может содержать слова «Яндекс», «Алиса», «Станция» и общеупотребительные команды.
