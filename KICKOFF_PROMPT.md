**Цель итерации 1 — самый минимальный рабочий каркас:**

1. Обработчик для Yandex Cloud Functions на Python (один файл, точка входа `handler(event, context)`), который:
   - корректно разбирает входной JSON Яндекс Диалогов;
   - на запуск навыка (`session.new == true`) отвечает приветствием с инструкцией, что умеет («запомни, что … лежит …» и «где лежит …»);
   - на любую другую фразу пока отвечает заглушкой-эхом (повторяет распознанную команду), `end_session: false`;
   - возвращает ответ строго в правильном формате (`response.text`, `response.tts`, `version`).
2. Никакой БД и YDB на этой итерации — только структура запрос/ответ и проверка, что навык вообще отвечает.
3. Сразу дай:
   - сам код;
   - 2–3 примера входного JSON (запуск навыка и обычная фраза), на которых я проверю логику на вкладке «Тестирование»;
